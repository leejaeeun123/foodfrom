## 00 — BRAND

### Brand Name

**푸드프롬 / FOODFROM**

`FOOD` + `FROM`. 여기서 `FROM`은 **편지의 발신인 표기**입니다.
편지 말미에 이름을 적듯, 푸드프롬은 보내는 사람의 자리에 섭니다.

```
From. 푸드프롬
```

### Slogan

| 용도 | 문구 |
|---|---|
| 패키지 / 박스 | 꾸미지 않은 제대로 고른 맛 |
| 웹 / SNS | 직접 보고, 직접 맛봤습니다. |

### Business Context

온라인 전용 밀키트 판매 브랜드. 오프라인 매장 없음.

| 채널 | 주소 |
|---|---|
| 네이버 스마트스토어 | smartstore.naver.com/foodfrom |
| 쿠팡 | shop.coupang.com/A01620210 |
| 11번가 | shop.11st.co.kr/stores/1229388 |
| G마켓 | minishop.gmarket.co.kr/foodfrom |
| 옥션 | stores.auction.co.kr/foodfrom |
| 카카오 톡딜 | store.kakao.com/foodfrom |

브랜드 접점의 100%가 **상세페이지 · 썸네일 · 배송 패키지**에서 발생합니다.
모든 디자인 규정은 이 세 곳에서 작동하는 것을 전제로 합니다.

### Target

**CORE**
- 1~2인 가구
- 2~30대 여성
- 요리가 서툴러 집에서 편하게 밀키트로 먹는 것을 선호
- 집에서 혼술을 즐김

**EXTEND**
- 4~50대 맞벌이 주부
- 시간이 부족하고, 가족과 한 끼 푸짐하게 먹을 수 있는 음식을 선호

## 01 — CONCEPT ★ 개정

### 브랜드 컨셉

> 꾸미지 않은 제대로 고른 맛
>
> 편지에는 정성껏 고른 말이 담기듯.
> 푸드프롬에는 정성껏 고른 맛이 담깁니다.
>
> 이 음식이 어떤 땅에서 자랐는지, 누가 어떻게 만들었는지.
> 우리는 직접 보고 맛봐서 확신한 것만 담습니다.
>
> 좋은 음식을 찾아 당신의 식탁으로 연결하는 것.
> 푸드프롬이 하는 일입니다.
>
> **From. 푸드프롬**

**Keyword** · 스토리, 안목, 맛, 진심, **편지**

### 무엇을 고치는가

기존 덱은 컨셉 문구에서 이미 '편지'를 말하고 있었으나,
**비주얼에서는 '연결'을 선물·배송 기호로 번역**했습니다. 컨셉과 비주얼이 어긋난 지점입니다.

| | 기존 | 개정 |
|---|---|---|
| '연결'의 은유 | **물건**이 오간다 | **마음**이 오간다 |
| 모티프 | 선물상자, 택배, 장바구니, 선택 | 봉투, 우표, 실링왁스, 편지지 |
| 로고 적용 | `ㅍ`에 선물상자 형상화 / `M`에 하트·리본 | 글자와 글자가 이어지는 **리가처** |
| 함의 | 유통 — 잘 보내드립니다 | 관계 — 골라서 씁니다 |

선물상자와 택배는 **누구나 쓰는 기호**입니다. 쿠팡도, 마켓컬리도, 모든 밀키트 브랜드가 씁니다.
반면 '편지'는 `FROM`이라는 이름에서만 나올 수 있는 은유이고, 브랜드 이름이 곧 근거가 됩니다.

### 개정 컨셉 — '편지'의 두 축

#### 축 1 · 물성 (Materiality)

편지를 **손에 쥐는 물건**으로 다룹니다. 배송 패키지가 곧 봉투라는 관점.

| 모티프 | 의미 | 주 적용처 |
|---|---|---|
| 봉투 플랩 | 열리는 순간 · 받는 사람 | 패키지, 섹션 구분자 |
| 우표 타공 (perforation) | 보낸 사람이 있다 | 썸네일 테두리, 라벨 |
| 실링왁스 · 인장 | 검수를 통과했다는 증표 | 인증 마크, 배지 |
| 편지지 · 레이스 | 담백한 정성 | 배경 텍스처 |
| 발신인 라인 | `From. 푸드프롬` | 전 접점 고정 서명 |

#### 축 2 · 글자 (Ligature)

'연결'을 **아이콘이 아니라 글자꼴에서** 표현합니다.
글자와 글자가 손글씨처럼 이어지는 형태가, 사람과 사람이 이어지는 것을 그대로 보여줍니다.

레퍼런스에서 관찰된 연결 방식:

| 사례 | 연결 지점 |
|---|---|
| magnolia | `f`–`l` 리가처 |
| mino | `m`–`i` 획 이음, 굵기 대비 |
| Lathr | `t`–`h` 크로스바 공유 |
| ROSÉ | `O`–`S` 외곽선 접합 |

공통점은 **하이컨트라스트 디스플레이 세리프**이며, 연결부가 장식이 아니라 구조입니다.

> **원칙** — 연결은 덧붙이는 것이 아니라, 원래 하나였던 것처럼 보여야 합니다.
> 리본을 매다는 것이 아니라, 획을 잇는 것.

### 배지 락업 (보조 방향)

Heritage · BETR. 유형의 **원형 배지 락업**은 '소인(postmark)'과 형태가 같습니다.
워드마크와 별개로, 인장·검수 마크 용도의 보조 락업으로 검토합니다.

```
    ·  DIRECTLY  TASTED  ·
   (        FOODFROM       )
    ·   EST. 2026   ·
```

### Don'ts

- 선물상자, 리본, 하트, 쇼핑카트, 택배 트럭, 체크 아이콘 사용 금지
- 봉투를 **아이콘으로 납작하게** 그리지 않기 — 물성(그림자, 종이 결)을 유지
- 편지 은유를 문구로 설명하지 않기 — "편지처럼 보내드려요" 같은 카피 금지. 형태로 말할 것
- 손글씨 폰트로 '편지 느낌'을 내지 않기 — 담백함이 우선

### Main Colors

| 이름 | HEX | 토큰 | 역할 |
|---|---|---|---|
| 아이보리 | `#FFFBEB` | `color/base` | 베이스. 편지지의 바탕 |

> 잉크·화이트는 운용에 필요한 최소 보조색입니다.

### 사용 비율

기존 덱의 스와치 비율을 그대로 따릅니다.

```
아이보리 ██████████████████████████████████  70%
번트오렌지 ███████████████                    30%
```

번트오렌지는 **면이 아니라 점**으로 씁니다. 로고, 인장, 가격, CTA 버튼.
상세페이지 전체를 오렌지로 덮지 않습니다.

### 대비 검증

| 조합 | 비율 | 판정 |
|---|---|---|
| 잉크 `#16130F` on 아이보리 `#FFFBEB` | 17.6:1 | AAA |
| 번트오렌지 `#D23A18` on 아이보리 `#FFFBEB` | 4.8:1 | AA (본문 가능) |
| 화이트 `#FFFFFF` on 번트오렌지 `#D23A18` | 4.4:1 | AA Large (18pt 이상만) |

> 번트오렌지 바탕 위 흰 글씨는 **큰 글자에만** 사용합니다. 작은 본문은 잉크로.

## 04 — LOGO DIRECTION

> **확정안 없음.** 재작업 예정이므로 방향성과 판단 기준만 기록합니다.

### 폐기된 방향

| | 내용 | 폐기 사유 |
|---|---|---|
| Alt 1 | `FOOD`의 `OO`를 미소로, `M`에 하트·리본 | 선물·배송 은유. 컨셉과 불일치 |
| Alt 2 | `ㅍ`에 선물상자 형상화 | 동일 |

### 새 방향의 판단 기준

1. **`FROM`이 읽혀야 한다** — 발신인 표기라는 이름의 근거가 보일 것
2. **연결은 획에서** — 덧붙인 오브젝트가 아니라 글자 구조의 연결
3. **16px에서 살아남을 것** — 썸네일과 스티커가 주 사용처
4. **1도 인쇄 가능** — 단색으로 무너지지 않는 형태

### 생산 제약 (기존 덱 기록)

> 1도 인쇄 동판 시 견적 300만원 초과 + 1~2개월 소요.
> 현 단계는 기성품(투명 비닐 + 냉동식품 백색 봉투)에 스티커로 법적 '영양표기'만 진행.
> 로고 확정 후 시안 수정 예정.

로고는 **스티커 단색 출력**을 최초 적용처로 상정하고 설계합니다.

### PACKAGE — 현행

> **전제** · 패키지 제작비 부담으로 전용 인쇄 포장재를 쓰지 않습니다.
> **기성 무지 포장재 + 스티커 1장**이 현재의 전부이며, 당분간 이 조건이 유지됩니다.

즉, **스티커가 브랜드의 유일한 물리적 면**입니다.
패키지 디자인 = 스티커 디자인이며, 모든 물성 규정은 이 한 장에서 작동해야 합니다.

#### 포장 유형

| 유형 | 제품 | 포장재 | 스티커 |
|---|---|---|---|
| 냉동 파우치 | 김치찜, 곰탕, 뼈없족, 아는떡볶이 | 백색 무지 파우치 (폴리에틸렌 내면) | 전면 중앙 · 컬러 |
| 진공 투명 | 편육 | 투명 진공 파우치 | 상단 · **흑백 영양정보만** |

배송은 **아이스박스 + 아이스팩 동봉 택배**.

#### 스티커 템플릿 (냉동 파우치)

현행 템플릿은 이미 브랜드 컬러 위에서 작동하고 있습니다. 구조를 규격으로 고정합니다.

| 영역 | 내용 |
|---|---|
| 배경 | 아이보리 계열 |
| 제품명 | 번트오렌지, 초대형 굵은 고딕, 좌측 정렬 |
| 브랜드 표기 | **`푸드프롬`** 우측 상단 고정 |
| 서브 카피 | 원료 함량 · 원산지 (제품명 하단) |
| 조리예 이미지 | 우측 상단 원형 마스크 + `조리예` 캡션 |
| 아이콘 | 냉동보관 · HACCP · 분리배출 |
| 표시사항 | 표 형식 — 제품명 / 내용량 / 품목보고번호 / 식품의유형 / 포장재질 / 소비기한 / 보관방법 / 제조원 / 유통전문판매원 / 원재료및함량 |
| 알레르기 | 번트오렌지 테두리 강조 박스 |
| 주의사항 | 본문 |
| 영양정보 | 하단 가로 표 · 아이보리 바탕 |
| 고객상담실 | `070-8814-5892` |

#### 규격 불일치 — 확인 필요

| 제품 | 원본 크기 | 비율 |
|---|---|---|
| 곰탕 | 1240 × 1476 | 1 : 1.19 |
| 뼈없족 | 620 × 738 | 1 : 1.19 |
| **아는떡볶이 (v3)** | 1299 × 1772 | **1 : 1.36** |

떡볶이만 세로로 길어 **레이아웃 리듬이 어긋납니다**.
파우치 규격 차이 때문이라면 그대로 두되, 아니라면 `1 : 1.19`로 통일합니다.

#### 갭 — 편육

편육 스티커는 **흑백 영양정보 표기뿐**이고 `푸드프롬` 표기조차 없습니다.
투명 진공포장이라 무지 파우치보다 오히려 배경이 좋은데, 브랜드가 전혀 실리지 않은 상태입니다.

> **우선 조치** — 편육 스티커에 최소한 `푸드프롬` 워드마크와 제품명을 넣습니다.
> 투명 배경을 살리려면 아이보리 면을 깔지 말고 **흰 글자 + 오렌지 포인트**로 뺍니다.

#### 편지 컨셉의 무료 적용안

**인쇄비가 늘지 않는** 범위 — 스티커 판만 수정하면 되는 항목입니다.

| 적용 | 방법 | 추가 비용 |
|---|---|---|
| 우표 타공 테두리 | 스티커 외곽을 반원 반복 라인으로 (도무송 아닌 **인쇄 라인**) | 없음 |
| 발신인 라인 | 하단에 `From. 푸드프롬` 한 줄 | 없음 |
| 소인 스탬프 | `조리예` 옆 또는 알레르기 박스 옆에 원형 배지 1도 | 없음 |
| 색 정리 | 배경 아이보리를 `#FFFBEB`로, 포인트를 `#D23A18`로 통일 | 없음 |

도무송(모양 재단)은 비용이 오르므로 **현 단계에서는 하지 않습니다.**
타공은 재단이 아니라 인쇄로 흉내 냅니다.

### 동봉 카드

편지 컨셉이 **가장 직접적으로 증명되는 지점**입니다.
제품 1개 단위로 들어가는 소형 카드, 아이보리 지류, 번트오렌지 1도 인쇄.

> 다만 현 예산 조건에서는 **후순위**입니다.
> 스티커 개선이 먼저이고, 동봉 카드는 스티커 판 수정이 끝난 뒤 검토합니다.
