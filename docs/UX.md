# UX Guidelines

> 푸드프롬을 어떻게 사는가. 지금 매출이 일어나는 곳은 **6개 마켓플레이스**이고, 자사몰은 먼 미래입니다. 이 문서는 마켓플레이스 운영(PART A)을 먼저 다루고, 자사몰(PART B)은 뼈대만 남겨둡니다.

오프라인 매장이 없으므로 **UX = 상세페이지 + 썸네일**입니다. 사실상 매출에 가장 직접 닿는 문서입니다.

## 02 · Detail Page

### 섹션 순서

상세페이지는 **편지의 순서**로 읽힙니다. 브랜드를 먼저 소개하고, 그다음 제품을 말합니다.

| 순서 | 섹션 | 목적 |
|---|---|---|
| 1 | 로고 | 누가 보냈는지 |
| 2 | 브랜드 편지 문단 | 신뢰도 확보 — 왜 이걸 골랐는지 |
| 3 | 제품 대표 컷 | 무엇인지 |
| 4 | 제품 설명 | 재료 · 출처 · 조리 시간 (담백한 톤) |
| 5 | 조리법 | 어떻게 먹는지 |
| 6 | 구성 · 중량 | 얼마나 오는지 |
| 7 | 표시사항 · 알레르기 | 법정 고지 |
| 8 | 배송 · 공지사항 | 아이스박스 + 아이스팩 |

> **2번이 핵심입니다.** 음식 소개 전에 브랜드 설명 문단을 넣어 신뢰도를 먼저 확보합니다. 이 문단은 항상 `From. 푸드프롬` 으로 닫습니다.

### 규정

```dodont
DO 브랜드 문단을 제품 설명보다 먼저
DO 재료 출처와 조리 시간을 숫자로
DO 아이보리 배경 · 번트오렌지는 점으로만
DONT 상세페이지 전체를 오렌지로 덮기
DONT 브랜드 문단 없이 제품 사진부터 시작
DONT 두 톤(설명 / 재치)을 한 문단에 섞기
```

## 03 · Thumbnail

썸네일은 **1장에서 브랜드가 식별되어야** 합니다. 검색 결과에서 푸드프롬 제품끼리 한 줄로 보였을 때 같은 브랜드로 읽히는 것이 목표입니다.

| 요소 | 규정 |
|---|---|
| 우표 타공 테두리 | 이미지 외곽에 반원 반복 |
| 소인 마크 | 원형 배지 · 번트오렌지 1도 |
| 제품명 | 검색어 기준 표기 |
| 배경 | 아이보리 · 크라프트 |

[상태: 개념만] 타공 지름·피치와 배지 지름이 `Brand.md` 04 에서 확정되어야 실제 적용이 가능합니다.

```dodont
DO 원물이 보이는 컷
DO 자연광 · 그림자 살리기
DONT 텍스트로 썸네일 덮기
DONT 플랫폼마다 다른 썸네일 쓰기
DONT 가짜 할인율 · 가짜 마감 표시
```

## 04 · Letter Copy

상세페이지 브랜드 문단을 쓰는 방법.

### 구조

```
안부  →  고른 이유  →  발신인
```

### 표본

```letter
안녕하세요.

이 음식이 어떤 땅에서 자랐는지, 누가 어떻게 만들었는지
우리는 직접 보고 맛봤습니다.

확신한 것만 담아 보냅니다.

From. 푸드프롬
```

### 규정

- 1인칭은 `우리`, 2인칭은 `당신`. **`고객님` 금지**
- 모든 문단의 마지막은 `From. 푸드프롬`
- 편지 은유를 **문구로 설명하지 않습니다** — "편지처럼 보내드려요" 금지

자세한 어휘 규정은 `BX.md` 04 · 08 을 따릅니다. [상태: 확정]

## 05 · UX Principles

Nielsen 10 휴리스틱을 채택하고, 푸드프롬 고유 원칙을 추가합니다. [상태: 미작성]

### 푸드프롬 고유 원칙 (후보)

| 원칙 | 뜻 |
|---|---|
| **Show the Sender** | 누가 골랐는지가 항상 보이게. 익명 유통의 반대가 브랜드의 근거입니다 |
| **No Fake Urgency** | 가짜 품절임박 · 카운트다운 타이머 금지. "꾸미지 않은"의 UX 번역입니다 |
| **Say What You Know** | 모르는 것은 모른다고. 배송일이 불확실하면 불확실하다고 씁니다 |
